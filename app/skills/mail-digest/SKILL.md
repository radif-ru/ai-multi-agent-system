Description: Сводка по почте: вызывает email_list, запускает stats.py для детерминированного подсчёта, интерпретирует результат.

# Skill: mail-digest

## Когда использовать

- Пользователь просит «сводку по почте», «сколько писем», «топ отправителей», «статистику по письмам».
- Нужно быстро оценить объём входящей почты без чтения каждого письма.

**Не использовать**, если пользователь просит прочитать конкретное письмо — для этого скилл `email-assistant` и tool `email_read`.

## Алгоритм

1. Вызови tool `email_list` с нужными параметрами (provider, unread_only, limit).
2. Сохрани JSON-вывод во временный файл (в `tmp_dir` пользователя).
3. Вызови `run_skill_script` с `skill="mail-digest"`, `script="stats.py"`, `args=["--input", "<путь_к_файлу>"]`.
4. Интерпретируй JSON-сводку из stdout: назови цифры (всего/непрочитанных), перечисли топ-3 отправителей, укажи разбивку по датам.
5. Верни результат в `final_answer` как краткий текстовый отчёт.

## Скрипты

| Скрипт | Назначение | Аргументы | Вывод |
|--------|------------|-----------|-------|
| `stats.py` | Подсчёт сводки по JSON-выводу `email_list` | `--input <file>` (или stdin) | JSON: `{total, unread, read, top_senders, by_date}` |

## Пример

Вход: пользователь пишет «дай сводку по почте».

1. `email_list({"limit": 50})` → `{"messages": [...], "warnings": []}`
2. Сохранить JSON в `tmp/mail.json`.
3. `run_skill_script({"skill": "mail-digest", "script": "stats.py", "args": ["--input", "tmp/mail.json"]})`
4. stdout: `{"total": 42, "unread": 12, "read": 30, "top_senders": [["alice@example.com", 8], ...], "by_date": {"2026-07-08": 5, ...}}`
5. `final_answer`: «Всего 42 письма (12 непрочитанных). Топ отправителей: alice@example.com (8), bob@example.com (5). За 2026-07-08 — 5 писем.»

## Чего избегать

- Не считай статистику в уме — для этого есть скрипт.
- Не читай тела писем для сводки — достаточно метаданных из `email_list`.
- Не забывай передать путь к файлу через `--input`, если JSON сохранён в файл.
