# Журнал внеспринтовой работы

Хронологический журнал правок, сделанных **вне активного спринта** — хотфиксы, правки по итогам аудита, мелкая синхронизация документации. Правила канала — [`process.md`](./process.md) §12.

Зачем: спринты остаются архивом (`process.md` §2 п.5), а «безымянных» изменений в обход доски не появляется (`process.md` §3 п.4). Записи журнала — источник кандидатов на задачи следующего спринта.

Формат записи (новые — снизу, хронологический порядок):

```markdown
- **YYYY-MM-DD** — `<type>(<scope>)`: что и зачем. Затронуто: `<файлы/области>`. Гейты: `preflight` зелёный.
```
