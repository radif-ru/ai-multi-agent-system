## 1. Цель спринта

Укрепить «инженерный каркас» проекта: процессные правила (порядок и дополнение задач, маршрутизация находок), автоматический контроль покрытия тестами, дисциплину конфигурации (никаких хардкодов мимо `.env`), а также безопасность файлового доступа (область видимости по пользователю в Telegram/MAX) и усиление выходного guard'а. Параллельно — обновить рантайм Ollama до актуальной версии, добавить скиллы по созданию и ревью pull request (MR), и привести всю документацию (особенно `README.md`) к актуальному, презентабельному виду.

Спринт намеренно собирает «качество + безопасность + процессы» в один заход, потому что эти изменения слабо связаны по коду, но сильно — по документации, и их выгоднее закрыть согласованно (одна сверка ссылок и README в конце).

## 2. Скоуп и non-goals

### В скоупе

- Процессные правила: `_board/process.md` (порядок/дополнение задач, маршрутизация находок), `_docs/instructions.md` (правило config → `.env`).
- Контроль покрытия: `pytest-cov`, порог в `pyproject.toml`, гейт в CI, DoD/`_docs/testing.md`.
- Дисциплина конфигурации: вынос оставшихся хардкодов в `Settings` + `.env.example`; авто-проверка синхронизации.
- Рантайм Ollama: bump Python-клиента, проверка совместимости, инструкции установки сервера в Ubuntu.
- Безопасность файлового доступа: per-user область видимости `read_file` для Telegram/MAX; флаг для консоли; заметка про MAX/API.
- Выходной guard (response sanitizer / «bastion»): точечное усиление + документ.
- Скиллы разработки: `pull-request-discipline`, `pr-review-discipline` + зеркала-симлинки.
- Документация: `README.md`, сверка ссылок, актуальность graphify, авто-проверка относительных ссылок.

### Вне скоупа (non-goals)

- Webhook, стриминг, DAG-планировщик, внешние онлайн-LLM — остаются в `_docs/roadmap.md`.
- Переписывание агентного цикла, памяти, multi-agent.
- Реальная установка системного пакета Ollama агентом (системное действие — выполняет пользователь по предложенной команде).
- Полный аудит покрытия до 85% по всем подпакетам — порог ставим по факту текущего покрытия, ужесточение — отдельная задача/спринт.
